# Le Tir Groupé

Web app privée de jeu biathlon pour 4 amis : brèves, quiz « Money Drop » et pronos podium.

**Statut : squelette v0.1 [TEST].** Les 3 onglets et le classement fonctionnent avec des données fictives (`lib/data.ts`). Pas encore de Supabase, d'API IBU, d'agents ni de notifications.

La documentation du projet est dans `docs/`.

## Lancer en local

```bash
npm install
npm run dev
```

Puis ouvrir http://localhost:3000.

## Déployer

Projet importé dans Vercel depuis GitHub : chaque push sur `main` redéploie l'app.
